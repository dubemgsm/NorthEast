⚠️ Configuration Required

To use this feature in a Codespace, you must provide the Public URL for port 5000.

  1. Go to the Ports tab in your terminal.
  2. Find port 5000.
  3. Right-click it -> Port Visibility -> Public.
  4. Copy the Forwarded Address and paste it below.
Default: http://localhost:5000
